Build it

cd remotion
npm install
npm run studio   # live preview
npm run render   # writes out/short.mp4

storyboard.json is the single source of truth. scripts/prep_remotion.py turns it into remotion/public/data.json, and the components read it through src/data.ts.

Assets and cost (fal.ai)

  • Images: fal-ai/flux/schnell, 4 steps, 768×1344, 3 images (horse, car, cockpit). Real-photo look, no on-image text.
  • Animation: fal-ai/ltx-video-13b-distilled/image-to-video, 480p, 2 hero shots only (car, cockpit). The horse uses Ken Burns.
  • Voice: fal-ai/kokoro/american-english, one call, then cleaned (highpass, 1.12x tempo, loudnorm).
  • Music and SFX: cassetteai/music-generator and cassetteai/sound-effects-generator, one 36 s bed plus two 1–2 s effects.
  • Total of 9 generation calls. Outputs are cached in assets/, so re-running costs nothing. See the costs page for the breakdown.
  • Mix: music ducks under speech, SFX at 30%, final -14.0 LUFS, true peak -3.8 dBFS.

Rebuild

export FAL_KEY=...                      # one command at a time, never in a file
python3 scripts/make_images.py
python3 scripts/make_video.py fal-ai/ltx-video-13b-distilled/image-to-video
python3 scripts/make_audio.py
# clean voice + word timestamps, then:
python3 scripts/prep_remotion.py && python3 scripts/mix_audio.py
cd remotion && npm run render
